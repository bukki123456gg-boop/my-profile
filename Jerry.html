SEC 02

รูปภาพประจำตัว

เหตุผลที่อยากเรียน Full Stack Web Development

ผมสนใจการพัฒนาเว็บไซต์ที่สามารถทำงานได้ครบทั้งส่วนหน้าบ้าน (Frontend) และหลังบ้าน (Backend) เพราะต้องการสร้างเว็บแอปพลิเคชัน ที่ใช้งานได้จริงตั้งแต่ต้นจนจบ รวมถึงเพิ่มโอกาสในการทำงานด้าน Software Development ในอนาคต

ความคาดหวังต่อวิชานี้

คาดหวังว่าจะได้รับความรู้เกี่ยวกับการพัฒนาเว็บไซต์แบบครบวงจร สามารถเชื่อมต่อฐานข้อมูล ออกแบบส่วนติดต่อผู้ใช้ และนำความรู้ไปพัฒนา โครงงานจริงได้

จุดอ่อนที่ต้องพัฒนาเกี่ยวกับทักษะ Programming และแนวทางการพัฒนา

จุดอ่อนของผมคือการออกแบบโครงสร้างโปรแกรมและการแก้ปัญหาที่ซับซ้อน ดังนั้นผมจึงตั้งใจฝึกเขียนโปรแกรมอย่างสม่ำเสมอ ศึกษาแนวคิดด้าน Algorithm และ Data Structure รวมถึงฝึกทำโจทย์จากเว็บไซต์ต่าง ๆ เพื่อพัฒนาทักษะการคิดเชิงตรรกะ
